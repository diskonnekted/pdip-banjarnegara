### **SLIDE 4 — PILAR 1: KONSOLIDASI KADER**
```
👥 SATU DATA, SATU IDENTITAS, SATU KOMANDO

Fitur Utama:
• Verifikasi identitas tunggal: setiap kader satu NIK, satu akun
• Struktur berjenjang visual: DPC → PAC → Ranting → Anak Ranting
• Garis komando jelas: siapa koordinasikan siapa, terpantau utuh
• Profil kader lengkap: riwayat, kompetensi, area penugasan

Manfaat Strategis:
✓ Eliminasi "massa fiktif" dalam laporan
✓ Evaluasi kinerja koordinator berbasis data riil
✓ Percepatan distribusi instruksi partai ke tingkat terbawah
```

### **SLIDE 5 — PILAR 2: PEMETAAN KEKUATAN WILAYAH**
```
🗺️ INTELIJEN SPASIAL: BANJARNEGARA DALAM GENGGAMAN

Fitur Utama:
• Peta digital 20 kecamatan + batas desa resmi

✓ Strategi kampanye presisi: fokus pada daerah kritis
✓ Penempatan relawan & saksi berbasis analisis spasial
```

### **SLIDE 6 — PILAR 3: LOGISTIK TRANSPARAN**
```
📦 SETIAP BUTIR BERHARGA, SETIAP RUPIAH BERTANGGUNG JAWAB

Fitur Utama:
• Request digital: PAC/Ranting ajukan kebutuhan via aplikasi
• Approval berjenjang: DPC setujui, gudang siapkan, kurir antar
• Tracking real-time: status "Dikirim" → "Diterima" dengan bukti foto
• Stok gudang terpantau: hindari penumpukan atau kekosongan

Manfaat Strategis:
✓ Cegah kebocoran: logistik sampai ke tangan penerima yang tepat
✓ Efisiensi anggaran: redistribusi cepat berdasarkan kebutuhan riil
✓ Akuntabilitas publik: laporan distribusi dapat dipertanggungjawabkan
```

## 🎁 BONUS: TIPS PRESENTASI EFEKTIF

### 🗣️ Delivery Strategy
```
• Buka dengan pertanyaan retoris: "Berapa kader aktif kita di Kecamatan X?"
• Gunakan analogi perjuangan: "Sistem ini seperti peta perang — tanpa peta, kita buta"
• Tekankan manfaat, bukan fitur: "Bukan 'ada GIS', tapi 'Bapak bisa lihat basis kita di mana'"
• Akhiri dengan call-to-action jelas: "Kami siap mulai pilot dalam 2 minggu"
```

### 🎨 Desain Visual
```
• Warna dominan: Merah (#CE1126), Hitam (#000000), Putih (#FFFFFF)
• Font: Gunakan font resmi partai jika ada, atau sans-serif modern (Inter, Poppins)
• Ikon: Konsisten gaya flat/line, hindari clipart generik
• Animasi: Minimal — cukup fade-in per poin, hindari efek berlebihan
```

### 📋 Lampiran Siap Cetak
```
• Handout 1 halaman: ringkasan 7 pilar + kontak tim
• Mockup dashboard: 3-5 screenshot kunci untuk dibagikan
• FAQ singkat: jawaban atas pertanyaan umum tentang keamanan, biaya, timeline
```
